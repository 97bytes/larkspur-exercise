# Team: Room <number>

Your team name is your breakout room number. The repo owner types it on the
first line, exactly as in the guide: replace `<number>` with your room number.
For Room 7, the first line is `# Team: Room 7`.

Then the repo owner replaces each `- <Name>` below with one teammate's name,
exactly as that person typed it in the guide. Add one more line for each extra
teammate, starting with `- `. Commit the file once. Nobody else changes it.

The review reads these names. Nothing else comes off the list. Your team still
decides in the moment who does what.
